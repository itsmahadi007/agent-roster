# One home, everything else on top: UI layout — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rearrange the app so people never get lost: the agent list is the only page; agent details,
Add agent, Help and What changed open above it and close with ✕ / Esc / a click outside. Same
features, same behaviour, better layout. **No feature may be lost** (§ Feature inventory).

**Architecture:** Frontend only (Svelte 5 in `app/src`). New overlay primitives (`Panel`, `Dialog`
with scrim, focus trap, Esc, scroll-to-top) host the existing content. `AgentDrawer` content moves
into an agent side panel; `AddAgent` becomes a dialog; `Help` / `Changes` render inside the panel;
`TopBar` becomes part of the app on Windows/Linux and fits around the native traffic lights on
macOS. Usage bar colors come from usage only. No backend command, event or core type changes.

**Tech Stack:** Svelte 5 + vitest + svelte-check, Tauri 2.12.

**Spec / mockup:** `docs/superpowers/specs/2026-11-10-ui-layout-mockup.html` (owner approved
2026-11-10, incl. the Mac title bar). Owner: "we are just rearranging the UI to make it better for
the user ... make sure that no feature gets left out. Everything should work just fine."

## Global Constraints

- Layout only. Every backend command (15) and event (`usage-checked`) keeps its callers.
- Every preview op keeps a UI path: `add`, `color`, `default`, `import`, `remove`, `rename`,
  `role`, `share`, plus `good-at` and `disable-limits` from the drawer.
- Every change still goes through preview → apply (PlanSheet) → journal → undo. No direct writes.
- No new dependencies. Keep fonts, radii, spacing. Keyboard: Esc closes, focus is trapped in the
  open layer and returns to what opened it, arrow keys still move through the list.
- Narrow window (< 600 px): the panel fills the window; ✕ stays top-right.
- macOS: native traffic lights stay (`titleBarStyle: Overlay`, `trafficLightPosition {16,20}`).
- No AI attribution in commits. Checks before merge: `npm test`, `npm run check`, `cargo fmt
  --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.

## Ledger of rulings

1. The list is the only page; first run stays a full screen because there is no list yet.
2. Agent details = right side panel; Add agent = centered dialog (mockup approved 2026-11-10).
3. Close is always ✕ / Esc / click outside; no "Back" links.
4. One sign-in place in the panel; "Sign in again" merges into Sign in / Switch account.
5. Bar color = usage only; agent color = identity only; coral/marigold leave the picker and are
   remapped for display only (no roster migration in this plan).
6. macOS keeps native traffic lights; Windows/Linux draw app-styled controls.
7. Default sign-in stays the browser; the Agent Roster window is a setting (owner, 2026-11-10).
