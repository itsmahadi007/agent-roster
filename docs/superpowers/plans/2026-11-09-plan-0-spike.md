# Plan 0 — De-risking Spike (throwaway)

> Throwaway. No TDD, no review gate. Results go into `docs/spike-results.md`; code is deleted or
> left in `spike/` and never imported by the real build.

**Goal:** prove the seven riskiest assumptions of the design (§10) on macOS, Windows and Linux
before Plan 1's decisions D1, D2 and D8 are locked.

**Spec:** `docs/superpowers/specs/2026-11-09-agent-roster-design.md` §10

## Where each check runs

| Check | macOS | Linux | Windows |
|---|---|---|---|
| Automated (no login) | owner's Mac | Docker: ubuntu:24.04, fedora:41, debian:12 | GitHub Actions `windows-latest` |
| Needs a real login | owner's Mac (already proven by the bash prototype) | Docker container with browserless device/URL flow | Windows 11 ARM VM in UTM on the owner's Mac, or 15 min on the boss's PC |

## Checks

- [ ] **S1 Login isolation per folder.** Two config folders per tool, sign each into a different
  account, run both at once. Pass: `claude auth status --json` shows two different `email`s;
  `codex login status` succeeds in both `CODEX_HOME`s. Record where each tool stores the
  credential per folder on each OS (file vs keychain/credential manager) without reading it.
- [ ] **S2 Launcher on PATH.** A shim named `spikeagent` in a user-owned bin folder runs from:
  macOS zsh/bash; Linux bash/zsh/fish; Windows cmd, PowerShell 7, Windows PowerShell 5.1,
  Windows Terminal, Git Bash. Pass: prints the env var it set. Windows: user PATH written via
  HKCU\Environment is visible in a new terminal without logoff.
- [ ] **S3 Agent calling agent.** Inside a running `claude` session, the agent runs
  `spikeagent -p "say OK"` (Claude) and `spikeagent2 exec "say OK"` (Codex). Pass: correct
  account answers; `CLAUDECODE` cleared; banner absent from captured output.
- [ ] **S4 Tauri 2 window + tray + open-terminal.** `npm create tauri-app` (Tauri 2.12.x,
  Svelte), add a tray icon with one menu item that opens a new terminal running `spikeagent`.
  Pass on all three OSes (Linux: GNOME under the UTM VM; Windows: Windows Terminal, cmd fallback).
- [ ] **S5 Codex limits on each OS.** Find the newest `sessions/**/*.jsonl` under `CODEX_HOME`
  and read the last `event_msg` with `payload.type == "token_count"` and `payload.rate_limits`.
  Pass: `primary.used_percent`, `primary.window_minutes`, `primary.resets_at` parsed.
- [ ] **S6 Unsigned installs.** macOS: an ad-hoc-signed `.app` fetched with `curl` into
  `~/Applications` opens with no Gatekeeper prompt. Windows: an unsigned `.exe` fetched by
  `irm | iex` runs with no SmartScreen prompt. Linux: AppImage runs on Ubuntu desktop.
- [ ] **S7 Headless.** A musl-static CLI binary runs in a bare Linux container over SSH;
  `codex login --device-auth` and `claude auth login` complete with the browser on another device.
