Agent Roster: one home, everything else on top

Layout proposal for the agent details and Add agent (frontend only). The list stays exactly as it is. Details and forms open above it and close with ✕, Esc or a click on the dimmed list, so you never leave home and never need a "Back" link.

What confuses people today
  1. Add agent leaves home. A full page replaces the list, opens scrolled to the middle (no title in view), and the only way back is a small "Back to your agents" link.
  2. Details open inside the list. A long section pushes the other agents away and mixes everyday actions with rare settings and Remove.
  3. Two ways back (back links on pages, expanding rows) and sign-in in two places ("Sign in" + "Sign in again").
  4. Add agent asks Color before Tool, the choice that matters most; a big empty "What will happen" box takes space.
The fix
  1. Add agent = a small dialog over the dimmed list: Tool → Name → Color, "More options" folded, one-line summary. Fits without scrolling.
  2. Agent = a side panel from the right: who it is and its week at the top, the two actions, then Settings, then Remove at the bottom, set apart.
  3. One way back everywhere: ✕ / Esc / click outside. Help and What changed use the same panel.
  4. One sign-in place: the panel's main button (Sign in, or Switch account when signed in).

Try it

Click a row, Add agent, or How it works inside the window. Close with ✕, Esc or a click on the dimmed list.

Windows: app icon and name on the left, minimize / maximize / close on the right, in the app's own colors (close turns red on hover). The bar is the app, not a separate Windows strip.

A red agent at 12% looks "almost out"; a yellow one looks like a warning. Red also means "limit reached", so the same color means two things.
Proposed: two separate jobs
  • Agent color = who. Only the dot and the name. Palette without warning hues:
  • Bar color = how much. The same for every agent:
    under 70%: calm (light grey)
    70–89%: amber, worth watching
    90%+ or limit reached: red, plus words ("limit reached, resets in …")
  • Existing coral/marigold agents move to the nearest new color automatically (with a note in What changed).

What goes where

Agent panel (top to bottom)
  1. Header: color dot, name, tool, status (ready / working / sign in / limit reached), ✕.
  2. This week: big bar, % used / left, reset time, "as of" if stale.
  3. Actions: Open in terminal ▾ · Sign in (only when needed) · "or type name" + Copy.
  4. Settings: name, color, role, good at, skills, default for claude/codex, Switch account.
  5. Remove agent, alone at the bottom, with its undo note.
Rules for the whole app
  1. The list is the only "page". Everything else is a panel or a dialog over it.
  2. Close is always ✕ top-right, Esc, or a click outside. No "Back" links.
  3. Opening anything starts at its top (no carried-over scroll).
  4. The dimmed list stays visible, so people always know where they are.
  5. Narrow window (< 600 px): the panel fills the window, ✕ still top-right.
